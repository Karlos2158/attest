# Тренажёр аттестации — EGO Bottego

Голосовой тренажёр для подготовки к аттестации консультанта по продажам.
Работает локально в браузере Chrome / Edge на Windows.

## Как запустить

1. Двойной клик по `start.bat`.
2. Откроется браузер: http://localhost:8765
3. Разрешите доступ к микрофону (значок в адресной строке).

Сервер работает, пока открыто чёрное окно. Закрыли окно — сервер остановился.
Можно сделать ярлык на `start.bat` и вынести на рабочий стол.

## С телефона в домашней сети

Сервер поднимает второй адрес — HTTPS для телефонов: **https://192.168.1.194:8766**
(компьютер и телефон должны быть в одной Wi-Fi / домашней сети). На компьютере
по-прежнему открывается http://localhost:8765, ярлык менять не нужно.

HTTPS нужен потому, что браузер телефона не даёт доступ к микрофону на обычном http.

Порядок:

1. На телефоне откройте https://192.168.1.194:8766 (или наведите камеру на `phone_qr.png`).
2. Первый раз появится предупреждение «Подключение не защищено» — «Дополнительно» → «Перейти».
   Это нормально: сертификат выпущен локально, для домашней сети.
3. Разрешите микрофон.
4. Хотите без предупреждений — один раз поставьте на телефон корневой сертификат:
   скачайте https://192.168.1.194:8766/ca.crt и в настройках Android
   «Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС».

Сертификаты лежат в `certs/` и выпущены на 2 года; перевыпуск — `python make_cert.py --force`
(нужен пакет `cryptography`). Если IP компьютера в сети изменился — перевыпустите сертификат,
иначе телефон снова покажет предупреждение.

Выключить сетевой доступ: запускать сервер с переменной `ATTEST_LAN=0`.
Другой порт: `ATTEST_LAN_PORT=9000`.

## Режимы

- **Тренировка** — приложение задаёт вопрос голосом, вы отвечаете своими словами,
  ИИ проверяет по смыслу и ставит оценку 0–5, разбирает: что верно, что упущено,
  как ответил бы преподаватель, и задаёт уточняющий вопрос.
- **Плеер** — список вопросов выбранной аттестации с галочками. Отметьте нужные,
  выберите отдельно голос вопросов и голос ответов, нажмите «Плей» — плеер прочитает
  вопрос первым голосом, эталонный ответ вторым, затем перейдёт к следующему вопросу.
  Есть пауза, стоп, предыдущий/следующий вопрос и полоса прогресса. Выбор вопросов и
  голоса запоминаются. Удобно для заучивания.
  В поле «Повторов» укажите, сколько раз прогнать весь список (по умолчанию 1),
  кнопка «🔁 Бесконечно» повторяет вопросы до нажатия «Стоп». «Стоп» запоминает место:
  следующий «Плей» продолжит с того же слова, а не с начала списка.
  Если услышали неверное ударение: остановите плеер и откройте «Правку словаря» —
  в разделе «Из последней фразы» появится именно тот кусок, который только что звучал.
- **Я спрашиваю** — вы задаёте вопрос голосом, приложение отвечает вслух по конспекту
  и показывает, из какого пункта взят ответ. Можно просить: «объясни проще»,
  «приведи пример из магазина». В чате тренер называет номер пункта, и вслух он
  произносится словами («вопрос один точка один»), потому что движок речи пропускает «1.1».
  На экране номер при этом остаётся обычным.
- **Экзамен** — 17 вопросов выбранной аттестации в случайном порядке, таймер 45 минут,
  без показа эталона, в конце протокол с оценками и кнопкой «Тренировать слабые».
- **Прогресс** — средний балл, успеваемость по блокам, список слабых вопросов,
  настройки голоса и модели.

## Первая / Вторая аттестация

Переключатель вверху справа:

- **Первая аттестация** — блоки 1–3, 17 вопросов (должность, технология продаж, продукт).
- **Вторая аттестация** — блоки 4–6, 17 вопросов (презентация, возражения, сервис, отчётность).

Прогресс по каждой аттестации считается отдельно.

## ИИ

По умолчанию — локальная модель `qwen3:14b` на машине SPQR (Ollama, 192.168.1.199:11434).
Интернет и оплата не нужны, ответ проверяется за 10–25 секунд.

В настройках можно выбрать `qwen3.8:27b` — точнее, но медленнее (около 1–1,5 минуты).

Для DeepSeek: получите ключ на platform.deepseek.com, вставьте его в
**Прогресс → Настройки → Ключ DeepSeek API** и выберите модель `DeepSeek API`.
Ключ хранится в `data/secrets.json` и в браузер не попадает.

Стоимость DeepSeek — копейки: примерно 10–20 рублей на 100 проверенных ответов.

## Данные

- Вопросы: `data/questions.json` (получены из Excel скриптом `parse_xlsx.py`).
- Статистика ответов: в браузере (localStorage), сброс — кнопка в настройках.
- Логи запросов: `logs/server.log`.
- Голос: распознавание — Chrome (нужен интернет), озвучка — локальный голос Silero
  (движок из `D:\AI CENTR\tts\.venv`, голос по умолчанию — Бая). Запасной — голос Windows «Ирина».
- Ударения и замены берутся из общего словаря проекта «Войс» (`D:\AI CENTR\tts\dict`).
  Поправить слово можно в отдельной программе «Правка словаря» — она на рабочем столе.
  Ударение — раздел «Ударение», произношение звуков (например, «бижутерия» → «бижутэрия») —
  раздел «Замены произношения».
  Речь режется на куски и следующий кусок скачивается, пока звучит текущий, поэтому
  пауз на стыках нет. В эталонном ответе можно поставить курсор в любое место —
  кнопка «Плей» начнёт читать оттуда, «Сначала» вернёт к началу.

## Telegram Mini App

Тренажёр можно открывать прямо в Telegram — бот **@EGO_attest_bot** даёт кнопку
«Открыть тренажёр». Внутри работает тот же интерфейс, что и на компьютере.

- Токен бота хранится в `data/secrets.json` (файл в `.gitignore`, в репозиторий не попадает).
- Публичный адрес записывается в `data/miniapp.json`:
  ```json
  { "public_url": "https://example.trycloudflare.com" }
  ```
  Пока адрес пустой, бот честно отвечает, что мини-приложение не опубликовано.
- Бот сам запускается вместе с сервером. Для доступа к `api.telegram.org` он использует
  локальный прокси Happ (`127.0.0.1:10809`); если прокси выключен — пробует напрямую.
  Другой прокси задаётся переменной `TELEGRAM_PROXY`.
- Публикация через Cloudflare Tunnel (бесплатно, без домена):
  ```bat
  cloudflared tunnel --url http://127.0.0.1:8765
  ```
  Затем впишите выданный `https://…trycloudflare.com` в `data/miniapp.json` и перезапустите
  тренажёр. Адрес быстрого туннеля меняется после перезапуска — обновите файл снова.
- Безопасность: снаружи (через туннель) API открывается только после проверки подписи
  Telegram `initData` и выдачи закрытой cookie. Домашняя сеть и `localhost` работают как раньше.
- Прямая ссылка на бота: `https://t.me/EGO_attest_bot`.

```bat
python parse_xlsx.py "путь\к\новому\файлу.xlsx"
```

## Файлы

- `server.py` — локальный сервер (без внешних библиотек, только стандартный Python).
- `telegram_bot.py` — бот-дверь в мини-приложение (кнопка «Открыть тренажёр»).
- `static/` — интерфейс: `index.html`, `style.css`, `app.js`, `logo.svg`,
  `telegram-web-app.js` (официальный скрипт Telegram, лежит локально).
- `start.bat` — запуск.
- `make_cert.py` — выпуск сертификатов для доступа с телефона (папка `certs/`).
- `phone_qr.png` — QR-код на адрес для телефона.
- `parse_xlsx.py` — разбор Excel.
- `bench.py`, `smoke.py` — служебные проверки (можно не трогать).

Логотип: если положить настоящий файл в `static/logo.png`, скажите — подключу его
вместо нарисованной SVG-эмблемы.
